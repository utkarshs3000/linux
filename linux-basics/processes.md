// Processes

&emsp;Process created:  
&emsp;sleep 600

&emsp;PID:  
&emsp;4050

&emsp;Commands:  
&emsp;sleep, echo, ps, ps aux, grep, kill

&emsp;Result:  
&emsp;I started the `sleep 600` process in the background and found its PID as 4050. I checked the process  
&emsp;to see its user, PID, parent process and command. After using `kill 4050`, I checked the PID again and  
&emsp;the process was no longer running.

&emsp;What I learned:  
&emsp;I learned how to start a process in the background, find its PID, check information about a running process and stop it.  
&emsp;This can be useful while investigating an unknown or suspicious process on a Linux system.
