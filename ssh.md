// SSH Service and Login

 &emsp;What I practiced:  
 &emsp;Checking the SSH service and connecting to the system using SSH.

 &emsp;Why I practiced it:  
 &emsp;SSH is commonly used to remotely access and manage Linux systems.

 &emsp;Commands used:        
 >systemctl status sshd  
 >ssh soclab@localhost  
 >whoami

 &emsp;Result:  
 &emsp;I confirmed that the SSH service was running and successfully logged in through SSH as the `soclab` user.

 &emsp;What the result means:  
 &emsp;I can check SSH status and connect to a Linux system using SSH.

 &emsp;Why this matters for a SOC analyst:  
 &emsp;It helps when checking remote logins, SSH activity and user access during an investigation.
