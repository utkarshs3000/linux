// Package Management

 &emsp;What I practiced:  
 &emsp;Checking installed packages and viewing package information in RHEL.

 &emsp;Why I practiced it:  
 &emsp;A security analyst should know what software is installed on a system.

 &emsp;Commands used:  
 >rpm -q openssh-server  
 >dnf info openssh-server  
 >sudo dnf install openssh-server  

 &emsp;Result:  
 &emsp;I checked the installed OpenSSH Server package and viewed its installed and available versions.

 &emsp;What the result means:  
 &emsp;I can check whether a package is installed and find its version and package details.

 &emsp;Why this matters for a SOC analyst:  
 &emsp;It helps when checking installed software, versions and possible outdated packages.
