// Environment Variables

 &emsp;What I practiced:  
 &emsp;Checking, creating and removing environment variables in RHEL.

 &emsp;Why I practiced it:  
 &emsp;Environment variables can affect how users, commands and programs behave.

 &emsp;Commands used:  
 >echo $USER  
 >echo $HOME  
 >echo $PATH  
 >env  
 >export  
 >unset  

 &emsp;Result:  
 &emsp;I checked common environment variables, created my own variable and then removed it.

 &emsp;What the result means:  
 &emsp;I can view and manage environment variables in a Linux session.

 &emsp;Why this matters for a SOC analyst:  
 &emsp;It helps when checking unusual user settings, paths or environment changes during an investigation.
